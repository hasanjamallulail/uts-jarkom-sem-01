===== A. BUKTI KONFIGURASI TIGA METODE =====

--- STATIC ROUTING R-HQ ---
ip route 10.10.20.0/24 10.0.0.2
ip route 10.10.30.0/24 10.0.0.6
ip route 10.10.40.0/24 10.0.0.10

--- RIP VERSION 2 R-HQ ---
router rip
 version 2
 no auto-summary
 network 10.0.0.0/30
 network 10.0.0.4/30
 network 10.0.0.8/30
 network 10.10.10.0/24
!

--- OSPF R-HQ ---
router ospf
 ospf router-id 1.1.1.1
 passive-interface eth4
 network 10.0.0.0/30 area 0.0.0.0
 network 10.0.0.4/30 area 0.0.0.0
 network 10.0.0.8/30 area 0.0.0.0
 network 10.10.10.0/24 area 0.0.0.0
!
end
